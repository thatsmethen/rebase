# Rebase icon

`Rebase.png` is the 1024-pixel source asset; `Rebase.icns` contains the macOS icon sizes used by the application bundle.

Created with the built-in image generation tool, then refined in a second image edit. The design brief was a front-facing macOS app icon: a dark graphite rounded square with two rising aqua / sea-glass audio ribbons, a clean restrained finish, transparent surroundings, and no text or existing product branding. The final edit removed light fringes and surface texture while preserving the two ribbons and overall composition.

The selected output was resized with macOS `sips`, assembled with `iconutil`, and stripped of ancillary identifying image metadata. The alpha channel is retained. This asset is application artwork, not research evidence.
